# Winter Bowling VR

## Project Overview

Winter Bowling VR is a cooperative multiplayer bowling game developed for a Mixed Reality course. The game was created in Unity and designed as a playful winter-themed VR experience for two players.

Players compete across multiple bowling lanes located on floating ice platforms while interacting through gesture-based mechanics, networked gameplay, and immersive environmental effects.

The project explored interaction techniques, networking, navigation methods, and collaborative gameplay mechanics in virtual reality environments.

---

## Game Concept

The game takes place in a snowy arctic environment consisting of multiple bowling lanes with increasing difficulty.

Players work together to travel between lanes using a shared ice floe while competing in bowling challenges that include dynamic obstacles such as animals blocking the lanes.

The focus of the project was on immersive interaction and synchronized multiplayer gameplay.

---

## Gameplay Flow

1. Players start at the first bowling lane
2. Bowling balls are created using hand gestures
3. Both players take turns throwing bowling balls
4. Players travel together to the next lane using the ice floe
5. Difficulty increases across lanes through additional obstacles

---

## Features

### Interaction
- Gesture-based bowling ball creation using fist gestures
- Physics-based bowling ball throwing
- Hand representation with claw interaction system
- Object manipulation with VR controllers

### Multiplayer Networking
- Networked bowling balls
- Synchronized player representations
- Shared synchronized environment objects
- Multiplayer interaction support

### Navigation
- Natural walking within the tracking area
- Gaze-directed navigation
- Cooperative distant travel using a shared ice floe

### Immersion
- Winter-themed environment
- Particle effects for bowling ball trails
- Audio feedback for:
  - bowling interactions
  - footsteps
  - environmental water sounds

### Difficulty Progression
- Multiple bowling lanes
- Increasing gameplay complexity
- Animal obstacles blocking bowling paths
